# Project 03: Autonomous Agentic AI Code Evaluator

## Objective
Build a multi-agent automated code review and test-generation harness.

## Architecture
- **Planner Agent**: Decomposes code submission into units of analysis.
- **Security Auditor**: Checks for OWASP vulnerabilities and insecure deserialization.
- **Performance Profiler**: Static analysis of loops, allocations, and async patterns.
- **Synthesizer**: Consolidates findings into an executive report with prioritized remediation.
