# Algorithmic Problem Solving Patterns

Guide to the 26 core algorithmic patterns:

1. **Two Pointers**: Opposite ends (converging), fast & slow (cycle detection), parallel pointers.
2. **Sliding Window**: Fixed size (subarray calculations) vs dynamic size (longest/shortest valid condition).
3. **Prefix Sums & Frequency Maps**: Range sum queries, subarray sum divisible by K, subarray XOR.
4. **Binary Search & Invariant Maintenance**: Monotonic predicates, search space reduction, search on answer.
5. **Monotonic Stacks & Queues**: Next greater element, daily temperatures, largest rectangle in histogram.
6. **Fast & Slow Pointers (Floyd's Cycle)**: Linked list cycle, middle of linked list, duplicate number.
7. **In-place Reversal of Linked List**: Reverse sub-lists, reverse K-groups.
8. **Tree DFS & Backtracking**: Path sums, LCA, permutation/combination generation, pruning.
9. **Tree BFS & Level-Order**: Shortest path in unweighted graphs, serialization, zigzag traversal.
10. **Two Heaps**: Median of a data stream, sliding window median.
11. **Subsets & Combinations**: Power set, combination sum with constraints.
12. **Modified Binary Search**: Rotated arrays, bitonic array search.
13. **Topological Sort (Kahn's & DFS)**: Dependency resolution, build order, course schedules.
14. **Union-Find (Disjoint Set Union with Path Compression & Rank)**: Connected components, cycle detection, redundant connections.
15. **Shortest Paths (Dijkstra / Bellman-Ford / Floyd-Warshall)**: Network delay time, cheapest flights with K stops.
16. **Dynamic Programming: 1D**: Fibonacci, Climbing Stairs, House Robber, Coin Change.
17. **Dynamic Programming: 2D Grid / Matrix**: Unique paths, minimum path sum.
18. **Dynamic Programming: Knapsack (0/1 & Unbounded)**: Subset sum, partition equal subset sum.
19. **Dynamic Programming: Longest Common Subsequence & Edit Distance**: String alignments, diff algorithms.
20. **Dynamic Programming: State Machine / Stock Trading**: Best time to buy and sell stock with cooldown/transaction fee.
21. **Interval Scheduling & Merging**: Meeting rooms, insert interval, non-overlapping intervals.
22. **Tries (Prefix Trees)**: Autocomplete, replace words, word search II.
23. **Bit Manipulation**: Single number, counting bits, reverse bits, bitmask DP.
24. **Greedy**: Jump game, gas station, task scheduler.
25. **Segment Tree & Fenwick Tree (Binary Indexed Tree)**: Range minimum queries, dynamic prefix sums.
26. **Matrix Traversal & Flood Fill**: Number of islands, rotting oranges, surrounded regions.
