# Engineering Mastery OS Commands

- `/start` — today's adaptive training session.
- `/diagnose` — baseline or updated competency assessment.
- `/dsa` — interactive DSA/LeetCode coaching.
- `/dotnet` — C# and .NET deep dive.
- `/backend` — ASP.NET Core/backend engineering.
- `/frontend` — Angular or React lesson.
- `/sql` — database and query optimization.
- `/lld` — low-level design exercise.
- `/hld` — high-level system design.
- `/fde` — customer engineering simulation.
- `/debug` — production debugging exercise.
- `/project` — next project milestone.
- `/agents` — agentic AI system design/build exercise.
- `/research [topic]` — adaptive source-backed research.
- `/interview` — mock technical interview.
- `/review` — review submitted code/design.
- `/revise` — spaced repetition.
- `/progress` — competency matrix and progress.
- `/weakness` — highest-impact gaps.
- `/challenge` — unfamiliar engineering challenge.
- `/checkpoint` — portable progress summary.
- `/plan` — revise roadmap.
- `/continue` — resume next unfinished task.

The orchestrator should interpret commands in context and preserve current progress.
