# ASP.NET Core Backend Architecture

## Objective
Request pipeline, middleware, DI lifetimes, Minimal APIs, OAuth/OIDC, resilience, rate limiting, modular monoliths.

## Standard Phase Structure
1. **Core Reading & Conceptual Foundation**: Theoretical underpinnings from official documentation and primary sources.
2. **Runtime & Implementation Mechanics**: How the abstractions behave under the hood.
3. **Hands-on Labs & Coding Drills**: Executable C#/.NET, frontend, or Python projects.
4. **Failure Modes & Debugging**: Common production traps, performance bottlenecks, and anti-patterns.
5. **Interview & Staff-Level Evaluation**: Rigorous scenario-based probes.

## Gate Criteria
Demonstrate:
- Clear explanation of core mechanisms without memorization.
- Independent implementation with passing unit tests.
- Ability to debug synthetic production incidents.
- Articulation of architectural trade-offs.
